# 🌤️ Weather Dashboard

A responsive **Weather Dashboard** that allows users to search for a city and view its current weather conditions and other useful weather information.

## 🚀 Features

* 🌍 Search weather by city
* 🌡️ Display current temperature
* 💧 Humidity information
* 💨 Wind speed
* ☁️ Weather conditions
* 📍 Location-based weather information
* 📱 Responsive and user-friendly design
* ⚡ Real-time weather data using an API

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive layout
* **JavaScript** – Functionality and API integration
* **Weather API** – Fetching real-time weather information

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a city name in the search box.
5. Click the search button to view the weather information.

## 🔌 API Integration

The application uses a weather API to retrieve real-time weather data based on the city entered by the user.
